# TechService

Sistema de Gerenciamento de Ordens de Serviço desenvolvido como projeto acadêmico da disciplina **Prática Profissional em Análise e Desenvolvimento de Sistemas**.

## Objetivo
Centralizar o gerenciamento de clientes, equipamentos e ordens de serviço de uma assistência técnica, acompanhando o atendimento desde o recebimento do equipamento até sua entrega.

## Funcionalidades previstas
- Autenticação de usuários
- Cadastro e consulta de clientes
- Cadastro de equipamentos
- Abertura e consulta de ordens de serviço
- Atribuição de técnico
- Registro de diagnóstico
- Registro e aprovação de orçamento
- Atualização do status da ordem
- Registro da conclusão e entrega
- Histórico e relatórios

## Arquitetura proposta
Aplicação web organizada em camadas:

`Interface Web -> Controller -> Service -> Repository -> Banco de Dados`

## Estrutura
- `docs/`: documentação e modelagem
- `frontend/`: futura interface web
- `backend/`: futura API e regras de negócio

## Status
Projeto em fase de elaboração/modelagem.
